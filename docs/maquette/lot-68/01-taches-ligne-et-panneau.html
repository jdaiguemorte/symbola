Tâches : la ligne type et son panneau

Décision D3 de la porte 2 : une seule forme pour une tâche. Une ligne type (le titre, qui ouvre la tâche ; une action rapide, « Fait » ; un menu pour le reste) et un seul panneau, le grand, repris sur « Aujourd'hui », « Tâches », la fiche d'un évènement et le téléphone, avec les mêmes mots.

À gauche, l'écran d'aujourd'hui (capture du relevé, données fictives) ; à droite, l'écran proposé, aux jetons actuels de DESIGN.md. Les cadres d'ordinateur sont réduits pour tenir côte à côte : « Taille réelle » les montre à 1 440 px. Les cadres de téléphone sont à 375 px, taille réelle, coupés à 812 px de haut : ce qui est sous le bord n'est pas visible sans défiler.

Cadres d'ordinateur : Aller à :
  • La ligne type
  • Sur « Aujourd'hui »
  • Dans la fiche (onglet Tâches)
  • Sur téléphone
  • Le panneau

1. La ligne type

Anatomie de la ligne, et ses quatre formes

Une ligne, une cible : le titre ouvre le panneau. Une action rapide, toujours au même endroit : « Fait ». Un menu « ⋯ » pour le reste, dont la suppression. Plus de case sans libellé, plus de rond, plus de « Modifier », « Reporter », « Supprimer » sur chaque ligne.

  1. 1Le titre est la seule cible : il ouvre le panneau de la tâche. Il est en encre, souligné d'un trait gris : un lien reconnaissable sans survol (C-83), sans prendre la couleur de l'action. Il a la moitié de la largeur : « Faire signer le contrat du photographe » tient sur une ligne (C-34).
  2. 2Trois informations, toujours dans cet ordre : l'évènement (ou « Hors évènement »), l'échéance avec son état en toutes lettres (« En retard de 5 jours », « Dans 4 jours »), qui s'en charge. Plus de colonne « Catégorie » vide : la catégorie est un filtre et un champ du panneau.
  3. 3Une action rapide, nommée : « Fait ». Un bouton qui en a l'air, avec son mot ; plus deux cases voisines dont on ne sait laquelle coche (C-35). Une fois faite, la ligne garde sa place dix secondes avec « Annuler » dans le message de retour (voir la page « Retour après action »).
  4. 4Un menu pour le reste : « Changer la date… », « Confier à… », « Ouvrir l'évènement », puis, séparé et en bas, « Supprimer ». Le rouge ne s'affiche plus onze fois par écran (C-34, C-83).

Constats traités

  • C-34 : le titre prend la moitié de la ligne au lieu de 17 % ; plus de colonne vide ; plus de rouge répété.
  • C-35 : une seule commande pour « c'est fait », avec son mot.
  • C-38 : une seule ligne type, déclinée en quatre formes qui disent les mêmes choses avec les mêmes mots.
  • C-83 : le titre se lit comme un lien sans survol ; l'état d'une échéance a toujours un mot et une icône.
  • C-36 (en partie) : « Changer la date… » remplace « Reporter ▾ » et « Modifier » sur la ligne ; la suite est sur la page de l'écran « Tâches ».

Règles de forme appliquées (D10)

Une cible : le titreUne action rapide : FaitUn menu : ⋯
  • Rien de destructeur répété sur chaque ligne : « Supprimer » est dans le menu, séparé.
  • Toutes les lignes ont la même hauteur (60 px) et rien ne s'y écrit sur deux lignes, sauf un titre très long.
  • Sur téléphone, toutes les commandes font 44 px.

Une tâche faite garde son panneau : le bouton plein disparaît, « Rouvrir la tâche » la remet à faire. C'est le chemin pour une tâche cochée par erreur, une fois passées les dix secondes d'« Annuler » (D1).

Constats traités

  • C-38 : un seul panneau, depuis tous les écrans ; un seul libellé, « Qui s'en charge », et des valeurs nommées (« Vous », « Bastien », « Les mariés », « Maison Lumen »).
  • C-32 : les collègues sont proposés dans « Qui s'en charge » (demande un changement de données, à spécifier au lot de réalisation).
  • C-90 : « Rang et jalon » devient « Place dans le rétroplanning » et « Étape clé ».
  • C-08 : « Supprimer » n'est plus à côté du bouton d'enregistrement : il est dans le menu, séparé, avec sa conséquence.
  • C-36 : l'échéance se change dans le panneau par un seul champ, le même que « Changer la date… » de la ligne.
  • D1 : « Rouvrir la tâche » dans le panneau d'une tâche faite.

Règles de forme appliquées

Une action principale : Marquer comme faiteZones : en-tête, champs, pied
  • Fenêtre longue de DESIGN.md : 860 px, deux colonnes, fond assombri, Échap ferme.
  • Le nom de l'évènement est un lien vers sa fiche (P-11).
  • Enregistrement à la sortie de chaque champ : choix à confirmer par Julien (voir la note) ; en création, un bouton « Créer la tâche ».
